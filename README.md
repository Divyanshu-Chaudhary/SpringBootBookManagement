# Spring Boot Book Management System

## Features
- User/Admin Login
- Add/Update/Delete Books
- Borrow & Return Books
- Fine Management
- File Upload
- Role Based Access

## Tech Stack
- Java
- Spring Boot
- Spring Security
- Hibernate/JPA
- MySQL
- Thymeleaf
- AWS EC2

## Run Locally
mvn spring-boot:run


Live Demo: http://3.110.220.225:8080
OR
http://devdivyanshu.space:8080/login
